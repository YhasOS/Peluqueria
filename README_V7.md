# Gema Estudio de Belleza - V7 rediseño GE

Incluye:
- Rediseño visual inspirado en la nueva carta beige/rose-gold.
- Logo/monograma GE en SVG: `public/images/ge-logo.svg`.
- Imagen corporativa y carta final en la portada.
- Servicios definitivos con rangos y añadidos solicitados.
- Script SQL: `SUPABASE_GEMA_V7_SERVICIOS_FINAL.sql`.

## Aplicar cambios

1. Descomprime encima de la carpeta actual del proyecto.
2. No borres `.env`.
3. Ejecuta en Supabase SQL Editor:
   `SUPABASE_GEMA_V7_SERVICIOS_FINAL.sql`
4. Prueba local:
   `npm.cmd run build`
   `npm.cmd run dev`
5. Sube a GitHub:
   `git add .`
   `git commit -m "Rediseño GE y servicios finales"`
   `git push`

Vercel redeplegará automáticamente.
