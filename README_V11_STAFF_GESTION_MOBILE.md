# V11 - Gestión completa desde panel trabajadora

Incluye:
- Panel `/staff` responsive para móvil.
- Botones en citas propias: Cambiar, Cancelar, Realizada.
- Las citas de compañeras son solo lectura.
- Resumen económico solo de la trabajadora logueada.
- El resumen cuenta solo citas marcadas como `completed`.
- Cambio de texto en login admin: Gema Estudio de Belleza.

Pasos:
1. Descomprimir sobre el proyecto.
2. Ejecutar `npm run build`.
3. Si compila: `git add . && git commit -m "V11 gestion staff mobile" && git push`.
